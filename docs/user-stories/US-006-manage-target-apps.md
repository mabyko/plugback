# US-006 · 어떤 앱을 복원할지 고른다

**우선순위:** P1 · **관련:** F-05.3

## 스토리

> **도킹 사용자로서**, 이 화면에서 복원할 앱을 목록에서 켜고 끄고 싶다.
> **그래야** 저장은 해뒀지만 지금은 자동으로 옮기고 싶지 않은 앱을 잠시 빼둘 수 있다.

## 인수 조건

**AC-1 · 목록 확인**
- **Given** 집 화면이 연결되어 있고 프로필에 앱 3개가 있다
- **When** 메뉴바를 연다
- **Then** 세 앱이 체크박스 목록으로 보인다
- **And** 각 앱이 지금 실행 중인지 알 수 있다

**AC-2 · 일시적으로 제외**
- **Given** Slack이 대상 앱으로 등록되어 있다
- **When** Slack의 체크를 해제한다
- **Then** 다음 복원부터 Slack은 이동하지 않는다
- **And** **Slack은 프로필에서 삭제되지 않는다.** 위치 정보가 남아 있다

**AC-3 · 다시 포함**
- **Given** AC-2 상태다
- **When** Slack을 다시 체크한다
- **Then** 저장해둔 원래 위치로 복원된다. 위치를 다시 지정할 필요가 없다

**AC-4 · 명시적 삭제**
- **Given** 더 이상 관리하지 않을 앱이 목록에 있다
- **When** 그 앱을 목록에서 삭제한다
- **Then** 프로필에서 완전히 제거된다
- **And** 저장(US-002)을 다시 해도 되살아나지 않는다. 그 앱의 창이 외장 화면에 있으면 새로 추가된다

**AC-5 · 화면별 목록**
- **Given** 집과 회사 프로필이 모두 있다
- **When** 회사 화면을 연결한 상태로 메뉴바를 연다
- **Then** 회사 프로필의 앱 목록만 보인다
