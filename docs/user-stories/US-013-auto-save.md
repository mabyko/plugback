# US-013 · 저장을 잊어도 어제 배치로 돌아온다 (자동 저장)

**우선순위:** P1 · **관련:** F-03.5, F-03.6, F-03.7 · **상태:** 일반 설정 (최초 켜짐)

## 스토리

> **도킹 사용자로서**, 저장 버튼 누르는 것을 잊어도 어제 퇴근할 때의 배치로 돌아오고 싶다.
> **그래야** 배치를 신경 쓰는 일 자체를 그만둘 수 있다.

## 인수 조건

**AC-1 · 켜져 있으면 알아서 따라온다**
- **Given** 일반 설정 「자동 저장」이 켜져 있다 (선택 이력이 없으면 켜짐)
- **When** 하루 일하고 케이블을 뽑는다
- **Then** 뽑기 직전의 마지막 유효 배치가 이 작업 환경의 저장본이 된다
- **And** 다음에 같은 조합을 연결하면 **그 배치로 복원된다** — 저장을 누르지 않았는데도
- **And** 화면을 추가해 다른 조합으로 넘어갈 때와 Plugback을 종료할 때도 같다

**AC-2 · 작업 중 이력은 복원 기준이 아니다**
- **Given** 자동 저장이 켜져 있고, 오늘 창을 여기저기 옮겼다
- **When** 「지금 복원」을 누른다
- **Then** 마지막으로 저장이 완료된 배치로 돌아간다. 옮긴 위치는 「저장 대기」로만 남는다
- **And** 수동 저장을 누르면 그 배치가 새 저장본이 되고, 그보다 오래된 이력은 버린다

**AC-3 · 어느 배치가 쓰이는지 보인다**
- **Given** 자동 저장이 켜져 있다
- **When** 메뉴바 카드를 연다
- **Then** 복원에 쓰일 저장본의 방식과 시각이 보인다 (「복원 소스 · 자동 · 오후 6:02」)
- **And** 저장 대기 이력의 유무와 마지막으로 확인한 시각이 보인다 (「저장 대기 · 2분 전 배치 — 환경을 떠날 때 저장」)

**AC-4 · 끄면 원래대로**
- **Given** 자동 저장을 끈다
- **Then** 저장 대기 이력은 버리고, 마지막 저장본은 그대로 복원에 쓰인다
- **And** 다시 켜면 그때부터 새로 모은다 — 켜는 것만으로 저장되지 않는다

**AC-5 · 오늘 안 켠 앱이 사라지지 않는다**
- **Given** 저장본에 Chrome·VSCode·Slack이 있고, 오늘은 Slack을 켜지 않았다
- **When** 자동 저장이 켜진 채로 하루를 보내고 케이블을 뽑는다
- **Then** **Slack 기록은 새 저장본에도 남는다** (US-002 AC-4와 같은 약속)

**AC-6 · 이 환경에서 닫은 창은 다음 저장까지 빠진다**
- **Given** 회사에서 Slack 창을 닫았다
- **When** 다음 날 회사 화면을 다시 연결한다
- **Then** 옛 저장본의 Slack 자리를 새 창으로 채우지 않는다 — 자동 저장을 껐어도 같다
- **And** 같은 환경에서 저장이 성공하면 그때부터 새 기록을 따른다

**AC-7 · 덮개를 여닫아도 저장되지 않는다**
- **Given** 자동 저장이 켜져 있고 외장 화면에 연결되어 있다
- **When** 덮개를 닫았다 열거나, 잠자기에서 깨어난다
- **Then** 저장본은 갱신되지 않는다 — 작업 환경이 실제로 바뀌지 않았기 때문이다 (US-009와 같은 게이트)

**AC-8 · 창이 조금씩 밀리지 않는다**
- **Given** 자동 저장으로 복원하는 일을 여러 날 반복한다
- **Then** 창 위치가 회차마다 조금씩 밀리지 않는다. 복원이 실패한 착지 위치도 다음 저장본이 되지 않는다

## 비고

이 카드는 US-002 AC-5("작업 중 이력은 복원 기준이 아니다")와 한 쌍이다. 지켜야 했던 것은
**사용자가 저장한 배치를 앱이 몰래 덮지 않는다**였고, 그것은 「저장 완료 시점을 환경 이탈·종료 전으로 고정」으로 남았다.

AC-8이 붙어 있는 이유: 복원은 몇 px 어긋나게 착지해도 성공으로 기록한다(F-02.5).
그 값을 자동 저장이 다시 기록하면 회차마다 창이 밀리고 **검증은 계속 통과한다.**
같은 설계의 다른 제품에서 실제로 열려 있는 결함이다 (Memmon #19).

2026-09-11에 실험실 「자동 슬롯」에서 일반 설정 「자동 저장」으로 옮겼다. 옛 「자동 슬롯」 선택은 한 번 이어받는다.
