# US-013 · 저장을 잊어도 어제 배치로 돌아온다 (실험실)

**우선순위:** P2 · **관련:** F-08 · **상태:** 실험실 (기본 꺼짐)

## 스토리

> **도킹 사용자로서**, 저장 버튼 누르는 것을 잊어도 어제 퇴근할 때의 배치로 돌아오고 싶다.
> **그래야** 배치를 신경 쓰는 일 자체를 그만둘 수 있다.

## 인수 조건

**AC-1 · 켜면 알아서 따라온다**
- **Given** 설정 창 「실험실」에서 자동 슬롯을 켰다
- **When** 하루 일하고 케이블을 뽑는다
- **Then** 뽑기 직전 배치가 자동 슬롯에 저장된다
- **And** 다음에 이 화면을 연결하면 **그 배치로 복원된다** — 저장을 누르지 않았는데도

**AC-2 · 내가 저장한 것은 앱이 건드리지 않는다**
- **Given** 자동 슬롯이 켜져 있다
- **When** 자동 저장이 여러 번 일어난다
- **Then** 내가 `[💾 지금 레이아웃 저장]`으로 저장했던 배치는 **그대로 남아 있다**
- **And** 자동 슬롯이 이상해져도 저장 버튼을 한 번 누르면 내 배치로 돌아온다

**AC-3 · 어느 배치가 쓰이는지 보인다**
- **Given** 자동 슬롯이 켜져 있다
- **When** 메뉴바 카드를 연다
- **Then** 복원에 쓰일 슬롯과 그 저장 시각이 보인다 (「복원 소스 · 자동 · 오후 6:02」)
- **And** 마지막으로 배치를 모은 시각도 보인다 (「수집 · 2분 전」)
- **And** 언제 저장된 것인지 보고 판단할 수 있다

> 수집 표시가 필요한 이유: 수집은 눈에 보이는 일을 하지 않는다.
> 이 줄이 없으면 트리거가 죽어 있어도 케이블을 뽑아 확정된 뒤에야 알게 된다 — 2026-08-18에 실제로 그랬다.

**AC-4 · 끄면 원래대로**
- **Given** 자동 슬롯을 켜고 쓰다가 마음에 들지 않는다
- **When** 실험실에서 끈다
- **Then** 복원은 내가 저장한 배치만 쓴다
- **And** 카드에서 복원 소스 줄이 사라지고, 켜기 전과 똑같아진다
- **And** 다시 켜면 자동 슬롯이 이어진다 — 껐다고 지워지지 않는다

**AC-5 · 꺼져 있으면 없는 기능이다**
- **Given** 자동 슬롯을 켠 적이 없다
- **When** 앱을 쓴다
- **Then** 카드에 이 기능의 흔적이 없다
- **And** 백그라운드에서 아무것도 모으지 않는다

**AC-6 · 오늘 안 켠 앱이 사라지지 않는다**
- **Given** 프로필에 Chrome·VSCode·Slack이 있고, 오늘은 Slack을 켜지 않았다
- **When** 자동 슬롯이 켜진 채로 하루를 보내고 케이블을 뽑는다
- **Then** **Slack 항목은 자동 슬롯에도 남는다** (US-002 AC-4와 같은 약속)

**AC-7 · 덮개를 여닫아도 저장되지 않는다**
- **Given** 자동 슬롯이 켜져 있고 외장 화면에 연결되어 있다
- **When** 덮개를 닫았다 열거나, 잠자기에서 깨어난다
- **Then** 자동 슬롯은 갱신되지 않는다 — 외장 화면 구성이 실제로 바뀌지 않았기 때문이다 (US-009와 같은 게이트)

**AC-8 · 창이 조금씩 밀리지 않는다**
- **Given** 자동 슬롯으로 복원하는 일을 여러 날 반복한다
- **When** 매번 복원과 자동 저장이 일어난다
- **Then** 창 위치가 회차마다 조금씩 밀리지 않는다

## 비고

이 카드는 US-002 AC-5("자동 저장 없음")를 뒤집은 것처럼 보이지만 그렇지 않다.
지켜야 했던 것은 **"사용자가 저장한 배치를 앱이 덮지 않는다"**였고, 그것은 AC-2로 남았다.
사고의 원인은 자동 저장 자체가 아니라 **한 칸에 둘이 쓰는 것**이었다.

AC-8이 붙어 있는 이유: 복원은 몇 px 어긋나게 착지해도 성공으로 기록한다(F-02.3).
그 값을 자동 저장이 다시 기록하면 회차마다 창이 밀리고 **검증은 계속 통과한다.**
같은 설계의 다른 제품에서 실제로 열려 있는 결함이다
(Memmon #19 — "windows gradually crawl up the screen with each sleep").

실험실인 이유는 졸업을 약속하지 않기 위해서다. 걷어낼 수 있어야 실험이다.
시나리오 11개의 검증 기록은 `auto-capture-simulation.html`에 있다.
