# US-005 · 내장 화면에서 하던 작업이 흐트러지지 않는다

**우선순위:** P0 · **관련:** 요구사항 다 / F-02.5, 비목표

## 스토리

> **도킹 사용자로서**, 화면을 연결해도 내장 화면에서 하던 작업은 그대로였으면 좋겠다.
> **그래야** 이동 중에 열어둔 창들이 옛날 배치로 리셋되는 일이 없다.

## 인수 조건

**AC-1 · 대상 앱이 아닌 창은 건드리지 않는다**
- **Given** 내장 화면에 메모장·미리보기·터미널이 떠 있고, 셋 다 현재 작업 환경의 저장 대상이 아니다
- **When** 외장 화면을 연결해 복원이 실행된다
- **Then** 세 창의 위치와 크기가 **1픽셀도 변하지 않는다**

**AC-2 · 대상 앱이어도 내장 화면 창은 건드리지 않는다**
- **Given** Chrome이 대상 앱이고, Chrome 창 하나가 내장 화면에 있다
- **And** 외장 화면에도 다른 Chrome 창이 있고, 그 창이 저장본의 자리에 대응한다. 내장 화면의 창은 저장 자리와 연결되지 않은 별도 창이다
- **When** 복원이 실행된다
- **Then** 외장 화면의 Chrome 창만 이동한다
- **And** 내장 화면의 Chrome 창은 그대로다

**AC-3 · 앱 재시작 후**
- **Given** Chrome을 완전히 종료했다가 다시 실행했다
- **When** 복원이 실행된다
- **Then** 현재 후보 창을 이동 거리 등을 기준으로 일대일 대응시켜 저장된 자리로 이동한다
- **And** 어느 창이 "그때 그 창"인지는 보장하지 않는다

**AC-4 · 보조 창 제외**
- **Given** 대상 앱의 설정 팝업이나 툴팁이 떠 있다
- **When** 복원이 실행된다
- **Then** 보조 창은 이동 대상이 아니다

**AC-5 · 분리 시 창을 움직이지 않음**
- **Given** 외장 화면에서 작업 중이다
- **When** 케이블을 뽑는다
- **Then** Plugback은 창을 움직이지 않고, 분리 뒤 macOS가 흩어 놓은 창도 다시 읽지 않는다
- **And** 자동 저장(US-013, 최초 켜짐)이 켜져 있으면 전환 전에 확보한 마지막 유효 이력을 떠나는 작업 환경에 저장한다
- **And** 자동 저장이 꺼져 있거나 저장이 실패하면 이전 저장 완료본을 유지한다

## 비고

AC-3은 기술적 한계에서 나온 **의도된 포기**다.
창에는 앱 재시작을 넘어 유효한 식별자가 없다. 완벽한 창 매칭을 시도하면 안 된다.
