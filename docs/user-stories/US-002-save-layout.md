# US-002 · 지금 배치를 이 화면의 레이아웃으로 저장한다

**우선순위:** P0 · **관련:** 요구사항 라 / F-03

## 스토리

> **도킹 사용자로서**, 창을 마음에 들게 배치한 뒤 버튼 하나로 그 배치를 이 화면의 레이아웃으로 저장하고 싶다.
> **그래야** 다음에 이 화면을 연결했을 때 같은 배치를 되찾는다.

## 인수 조건

**AC-1 · 저장**
- **Given** 외장 화면에 Chrome과 VSCode를 배치해두었다
- **When** 메뉴바에서 `[💾 지금 레이아웃 저장]`을 누른다
- **Then** 두 앱의 위치가 이 화면의 프로필에 저장된다
- **And** 저장됐다는 것을 화면에서 확인할 수 있다

**AC-2 · 내장 화면 창은 저장하지 않는다**
- **Given** Slack이 맥북 화면에 떠 있다
- **When** 저장을 누른다
- **Then** Slack은 프로필에 들어가지 않는다

**AC-3 · 걸친 창**
- **Given** 창 하나가 두 화면에 걸쳐 있다
- **When** 저장을 누른다
- **Then** 창의 **중심점**이 있는 화면에 속한 것으로 저장된다

**AC-4 · 병합 — 꺼둔 앱이 사라지지 않는다**
- **Given** 집 프로필에 Chrome·VSCode·Slack이 등록되어 있고, 오늘은 Slack을 켜지 않았다
- **When** 저장을 누른다
- **Then** Chrome과 VSCode의 위치는 갱신된다
- **And** **Slack 항목은 프로필에 그대로 남는다**
- **And** 다음에 Slack을 켜고 이 화면을 연결하면 Slack도 복원된다

**AC-5 · 자동 저장 없음**
- **Given** 외장 화면에서 창을 여기저기 옮기며 작업한다
- **When** 저장 버튼을 누르지 않는다
- **Then** 프로필은 변하지 않는다
- **And** 케이블을 뽑아도 프로필은 변하지 않는다

## 비고

AC-5가 이 카드의 핵심이다. 자동 저장은 **복원이 부분 실패한 상태를 덮어써서 원본을 잃게 만든다.**
저장 시점을 사용자가 정하는 한 이 사고는 일어나지 않는다.
