# US-012 · 저장된 작업 환경을 한눈에 관리한다

**우선순위:** P2 · **관련:** F-05.6, F-04

## 스토리

> **도킹 사용자로서**, 지금 연결돼 있지 않은 화면 조합의 저장본도 보고 지울 수 있으면 좋겠다.
> **그래야** 더는 안 쓰는 회사 화면의 기록을 집에서도 정리할 수 있다.

## 인수 조건

**AC-1 · 전체 목록**
- **Given** 집과 회사 화면의 프로필이 있고, 지금은 집 화면만 연결되어 있다
- **When** 설정 창을 연다
- **Then** 두 작업 환경이 모두 보인다 — 연결 여부와 무관하게
- **And** 각 항목에서 화면 이름(조합), 앱 수, 창 위치 기록 수, 복원 소스(수동/자동·시각)를 알 수 있다

**AC-2 · 작업 환경 삭제**
- **Given** 더는 안 쓰는 조합의 저장본이 목록에 있다
- **When** 그 작업 환경을 삭제한다
- **Then** 화면 이름과 앱·창 수를 보여주는 확인을 한 번 거친다 — 되돌릴 수 없는 명시적 동작이다
- **And** 확인하면 목록에서 사라지고, 다시 저장하지 않는 한 되살아나지 않는다

**AC-3 · 삭제된 화면을 다시 연결하면**
- **Given** 프로필을 삭제한 화면이 있다
- **When** 그 화면을 연결한다
- **Then** 저장본 없는 조합으로 동작한다 — 아무 창도 움직이지 않는다 (US-001 AC-3)

**AC-4 · 이전 버전의 기록**
- **Given** 이전 버전의 화면별 기록(profiles.json)이 있다
- **When** 새 버전을 처음 실행한다
- **Then** 화면 하나짜리 작업 환경으로 가져오고 원본 파일은 그대로 둔다. 여러 화면 조합과 Space별 위치는 다시 저장해야 기록된다는 안내가 설정 창에 보인다

## 비고

카드(US-006)는 "지금 이 화면"의 대상 앱만 다룬다. 이 카드는 그 바깥 — 연결되지 않은 화면들의
기록 — 을 다루는 유일한 경로다. Stay의 `Edit Stored Windows…`(별도 편집 창)가 같은 역할의 선례다.
