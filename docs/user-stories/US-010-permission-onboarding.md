# US-010 · 처음 켰을 때 무엇을 해야 하는지 안다

**우선순위:** P1 · **관련:** F-06.1, F-06.2

## 스토리

> **도킹 사용자로서**, 앱을 처음 켰을 때 어떤 권한이 왜 필요한지 알고 바로 설정하고 싶다.
> **그래야** 권한 없이 아무것도 안 되는 상태로 방치하다 앱을 지우지 않는다.

## 인수 조건

**AC-1 · 첫 실행 안내**
- **Given** 손쉬운 사용 권한을 아직 주지 않았다
- **When** 앱을 처음 실행한다
- **Then** 권한이 필요하다는 안내가 보인다
- **And** 왜 필요한지 한 문장으로 설명한다
- **And** 시스템 설정의 해당 위치로 바로 갈 수 있다

**AC-2 · 권한 없이 동작 시도하지 않음**
- **Given** 권한이 없다
- **When** 외장 화면을 연결한다
- **Then** 복원을 시도하지 않는다 — 저장도 하지 않는다(권한 없는 빈 열거로 프로필을 덮어쓰지 않기 위해). 게이트는 모든 명령 안에 있다
- **And** 실패 오류를 반복해서 띄우지 않는다. 권한이 없다는 상태만 조용히 표시한다

**AC-3 · 권한 부여 후 즉시 동작**
- **Given** 안내를 따라 권한을 허용했다
- **When** 앱으로 돌아온다
- **Then** **재시작 없이** 정상 동작한다
- **And** 권한이 허용됐다는 것이 화면에 반영된다

**AC-4 · 화면 기록 권한은 요구하지 않는다**
- **Given** 앱을 설치하고 사용한다
- **When** 모든 기능을 사용한다
- **Then** '화면 기록' 권한 요청이 **한 번도 뜨지 않는다**
- **And** 주기적인 권한 재승인 알림도 뜨지 않는다

**AC-5 · 권한이 회수된 경우**
- **Given** 정상 동작 중이었는데 사용자가 시스템 설정에서 권한을 껐다
- **When** 복원이 실행될 상황이 온다
- **Then** 조용히 실패하지 않고, 권한이 없다는 것을 메뉴바에서 알 수 있다 → US-008

## 비고

AC-4는 제품 성격을 지키는 조건이다. 화면 기록 권한을 요구하는 순간 이 앱은
"조용한 유틸리티"가 아니라 "주기적으로 뭔가 묻는 앱"이 된다.
