# US-003 · 집과 회사가 서로 다른 레이아웃을 갖는다

**우선순위:** P0 · **관련:** 요구사항 가 / F-01.4, F-01.6, F-04

## 스토리

> **도킹 사용자로서**, 집 4K 화면과 회사 와이드 화면이 각각 다른 배치를 저장해 뒀으면 좋겠다.
> **그래야** 회사에서 맞춘 배치가 집 배치를 덮어쓰지 않는다.

## 인수 조건

**AC-1 · 독립 프로필** — 최소요구사항 1장의 핵심 시나리오
- **Given** 집 화면에 레이아웃 A를 저장했다
- **When** 회사 화면을 연결하고 레이아웃 B를 저장한 뒤, 다시 집 화면을 연결한다
- **Then** 레이아웃 A가 복원된다. B로 덮어써지지 않았다

**AC-2 · 재연결 후에도 같은 화면으로 인식**
- **Given** 집 화면 프로필이 있다
- **When** 케이블을 뽑았다 다시 꽂는다
- **Then** 같은 화면으로 인식하고 같은 프로필을 적용한다

**AC-3 · 포트를 바꿔 꽂아도 같은 화면**
- **Given** 집 화면을 오른쪽 USB-C 포트에 꽂아 쓰고 있었다
- **When** 왼쪽 포트에 꽂는다
- **Then** 같은 화면으로 인식한다. 새 프로필이 생기지 않는다

**AC-4 · 같은 모델 두 대 구분**
- **Given** 같은 모델의 화면 두 대를 함께 쓴다
- **When** 각각에 다른 레이아웃을 저장한다
- **Then** 두 화면은 서로 다른 프로필을 갖는다

**AC-5 · 외장 화면 2대 동시 연결**
- **Given** 외장 화면 두 대의 프로필이 각각 있고, 같은 앱이 양쪽 프로필에 등록되어 있다
- **When** 두 대를 함께 연결한다
- **Then** 각 화면의 프로필이 적용된다
- **And** 겹치는 앱의 창은 **한 번만** 움직인다. 두 화면 사이를 오가지 않는다

**AC-6 · 식별 실패 시**
- **Given** 화면을 고유하게 식별할 수 없다
- **When** 그 화면을 연결한다
- **Then** 아무 창도 움직이지 않는다. 잘못된 프로필을 적용하지 않는다

## 비고

**보류 아이디어 (v1 이후, 2026-08-16):** 프로필 없는 새 화면이 기존 프로필의 화면과 같은 모델이면, 그 프로필을 시작점으로 **복사할지 제안**한다. 복사 후 두 프로필은 독립이다.
같은 모델을 자동으로 한 프로필로 묶지 않는 이유: 집·회사에 같은 모델을 두면 저장이 서로를 덮어써 핵심 시나리오가 깨지고, 동시 연결(AC-4)에서는 화면 구분이 사라진다.
