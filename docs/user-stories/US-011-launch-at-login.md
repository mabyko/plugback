# US-011 · 켜두면 알아서 돌아간다

**우선순위:** P2 · **관련:** F-06.3, F-07

## 스토리

> **도킹 사용자로서**, 앱을 한 번 설정해두면 그 뒤로는 존재를 잊고 싶다.
> **그래야** 매번 실행하는 것을 기억할 필요가 없다.

## 인수 조건

**AC-1 · 로그인 시 자동 실행**
- **Given** 로그인 시 자동 실행이 켜져 있다
- **When** 맥을 재시작하고 로그인한다
- **Then** 앱이 자동으로 실행되어 메뉴바에 있다
- **And** 창이 뜨거나 포커스를 뺏지 않는다

**AC-2 · 끌 수 있다**
- **Given** 자동 실행이 켜져 있다
- **When** 설정에서 끈다
- **Then** 다음 로그인부터 자동 실행되지 않는다

**AC-3 · 유휴 시 조용하다**
- **Given** 앱이 실행 중이고 화면 구성에 아무 변화가 없다
- **When** 몇 시간이 지난다
- **Then** CPU를 쓰지 않는다. 주기적으로 무언가를 확인하지 않는다
- **And** 배터리 사용량 목록에 눈에 띄게 나타나지 않는다

**AC-4 · 복원은 빠르다**
- **Given** 외장 화면을 연결했고 신호가 안정됐다
- **When** 복원이 시작된다
- **Then** 1초 안에 끝난다 (「새 창 열기」 옵션으로 창 등장을 기다리는 경우 제외 — F-07)
- **And** 그동안 메뉴바는 응답한다

**AC-5 · 프로필 파일이 손상된 경우**
- **Given** 프로필 파일이 손상되어 읽을 수 없다
- **When** 앱을 실행한다
- **Then** **앱이 종료되지 않는다**
- **And** 손상된 파일을 백업하고 초기 상태로 시작한다
- **And** 무슨 일이 있었는지 사용자에게 알린다
