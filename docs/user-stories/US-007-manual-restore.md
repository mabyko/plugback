# US-007 · 원할 때 직접 복원한다

**우선순위:** P1 · **관련:** F-05.2, F-05.4, F-05.5

## 스토리

> **도킹 사용자로서**, 화면을 연결한 뒤에 켠 앱이나 손으로 옮겨버린 창을 버튼 하나로 다시 정렬하고 싶다.
> **그래야** 케이블을 뽑았다 꽂지 않아도 원래 배치를 되찾는다.

## 인수 조건

**AC-1 · 수동 복원**
- **Given** 외장 화면이 연결되어 있고, 창 몇 개를 손으로 옮겨 어질러졌다
- **When** `[⚡ 지금 레이아웃 복원]`을 누른다
- **Then** 대상 앱들이 저장된 자리로 돌아간다
- **And** 자동 복원과 똑같은 규칙이 적용된다. 꺼진 앱은 건너뛰고 내장 화면 창은 건드리지 않는다

**AC-2 · 연결 후에 켠 앱**
- **Given** 화면을 연결한 뒤에 Slack을 실행했다. 자동 복원은 이미 끝난 뒤다
- **When** 수동 복원을 누른다
- **Then** Slack도 저장된 자리로 이동한다

**AC-3 · 단축키**
- **Given** 다른 앱을 쓰고 있다
- **When** 단축어 앱에서 직접 지정해 둔 단축키를 누른다 (기본 할당은 없다 — F-05.5)
- **Then** 메뉴바를 열지 않고도 복원이 실행된다
- **And** 이미 복원이 진행 중이었다면 「이미 복원 중입니다」로 구별해 응답한다 — 조용한 무시가 아니다

**AC-4 · 수동 복원 모드**
- **Given** 카드 푸터의 「자동 복원」 스위치를 껐다 (수동 복원 모드)
- **When** 외장 화면을 연결한다
- **Then** 자동으로 복원되지 않는다
- **And** `[⚡ 지금 레이아웃 복원]`이나 단축키를 눌러야 복원된다

**AC-5 · 프로필 없는 화면에서**
- **Given** 프로필이 없는 화면이 연결되어 있다
- **Then** 카드의 `[⚡ 지금 레이아웃 복원]` 버튼은 비활성이고, 헤더가 「프로필 없음」을 보여준다 — 누를 수 없으니 아무 창도 움직이지 않는다
- **And** 단축어로 실행하면 「복원할 프로필이 없습니다」로 응답한다
