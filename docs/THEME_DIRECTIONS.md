# Plugback 테마·구성 시안 4종

2026-09-05. 유명 앱의 시각적 원칙을 메뉴바 카드에 적용한 탐색 기록이다. 후속 요청으로 A–D를 네이티브 카드에 구현하고, 레이아웃과 색상을 독립 설정으로 분리했다.

## 네이티브 적용

2026-09-07 밀도 조정: HTML 시안의 비율보다 메뉴바 사용성을 우선한다. A–D의 헤더는 화면 이름·연결 상태와 프로필 요약 두 줄로 정리하고 B의 큰 아이콘·슬로건·별도 숫자 영역을 제거했다. 공통 좌우 여백은 20pt, 앱 행은 기본 30–34pt, 아이콘은 20pt, 동작 버튼은 최소 32pt로 맞췄다. C는 명령 설명, D는 Space 구획을 유지한다. 마지막 복원 결과·시각은 한 줄에 모으고 실패 안내는 접지 않는다. 저장하지 않는 앱은 개수를 표시해 기본 접고, 직접 체크를 끄면 펼친다. 앱 목록의 스크롤바는 오른쪽 여백에 놓고, 외장 화면이 하나일 때 복원 소스는 버튼 아래에 고정한다. 아래 시안 설명은 탐색 당시의 기록이다.

프레임·설정 점검: D의 6pt 프레임 안쪽에 12pt 곡선을 적용해 배경과 푸터의 네모난 모서리를 잘랐다. A–C도 같은 `CardSurface`를 사용한다. 배지는 줄바꿈하지 않고, C 헤더의 상단 여백도 같은 표면색으로 채운다. 설정은 모양·일반·프로필·실험실로 나누고, 관련 설명을 선택 항목과 묶었다. 렌더 검사는 바깥 프레임까지 포함하며 D 안쪽 모서리의 픽셀과 설정 4화면의 라이트·다크도 확인한다.

사용감 보정: C의 보조 명령은 설명을 도움말로 옮겨 한 줄로 줄이고, 주요 명령의 설명은 유지한다. 앱 행 전체가 대상 선택 영역이며, 행·버튼의 hover/눌림 피드백을 제공한다. 삭제 버튼은 선택 영역 밖에 둔다. B의 제목과 화면 기호를 소폭 줄여 목록과 동작에 시선을 돌린다. 팔레트는 유지한다.

시안 일치 보정: 기본 버튼의 캡슐 모양·시스템 강조색을 팔레트 기반 6pt 모서리 버튼으로 바꾸고, 체크박스·스위치도 선택 색상을 따른다. 중간 구분선을 시안 위치로 줄이고 B의 숫자 요약, C의 강조 배경·아이콘 타일, D의 Space 번호·보조 색 구획, 작은 푸터를 복구했다. `soft`·`accentSoft`를 분리해 시안의 표면 위계를 유지한다. 실데이터가 없는 Space 번호·개수는 만들어내지 않는다.

세이지 후속 조정: 배경·보조 표면·외곽 프레임의 녹색기를 제거했다. 라이트는 따뜻한 회백색, 다크는 중립 차콜을 쓰고 녹색은 강조색에만 남긴다. 아래 최초 시안의 세이지 색상표는 탐색 당시 기록이다.

설정 → 모양에서 레이아웃 4종 × 색상 4종을 자유롭게 조합한다. 밝기도 시스템/라이트/다크 중 별도로 선택한다. 기본값은 B(여유 있는 목록) + Porcelain + 시스템 설정이다. 예를 들어 D의 Space 구획에 Porcelain 블루를 적용할 수 있다. 선택값은 각각 유지되며 프로필과 복원 정책에는 영향을 주지 않는다. 아래 HTML의 방향별 색 조합은 최초 탐색 기록이고, 실제 앱 색 정의는 `App/Plugback/CardAppearance.swift`에 있다.

검증: Debug/Release 빌드, App 테스트 18개, 코어 테스트 161개 통과. App 테스트에는 행의 빈 영역 클릭·독립 저장·알 수 없는 설정값의 기본값 처리·열린 뷰의 설정 변경 관찰·8개 팔레트의 텍스트 대비·페이크 앱 4개·Space 2개를 캡처·복원한 카드 32개 조합과 설정 8개 화면 렌더가 포함된다. D의 안쪽 곡선은 프레임 픽셀과 비교해 검사한다. 네이티브 이미지는 XCTest 결과에 첨부하며 A–D와 설정 네 화면을 시각 확인했다. 실제 메뉴바 패널에서의 화면 재연결·VoiceOver·확대 글꼴 검증은 이번 자동 검사에 포함하지 않았다.

## 네 방향의 차이

| 시안 | 구성 | 완성도를 만드는 요소 | 고급스러움의 방향 | 주의할 점 |
| --- | --- | --- | --- | --- |
| A · Graphite | 짧은 헤더 → 고정 액션 → 촘촘한 목록 | 정렬·밀도·짧은 이동 거리 | 그래파이트와 은은한 바이올렛, 절제된 전문 도구 | 익숙하지만 개성은 약하다. |
| B · Porcelain | 큰 제목 → 액션 → 프로필 요약 → 여유 있는 목록 | 명확한 시선 순서·읽기 쉬운 행 | 따뜻한 백색과 블루, 정돈된 Mac 앱 | 네 시안 중 카드가 긴 편이다. |
| C · Command | 화면 식별 → 복원 명령 → 저장 명령 → 대상 목록 | 동작과 설명의 결합·빠른 실행 | 따뜻한 차콜과 코랄, 명령 도구의 정밀함 | 명령 팔레트에 익숙하지 않으면 A/B보다 낯설다. |
| D · Sage | 색 프레임 → 액션 → Space별 내부 구획 | 소속 앱과 안내를 한 덩어리로 읽기 | 세이지와 라일락의 조합, 개성 있는 개인 도구 | 기존 브랜드에서 가장 멀다. 번호·문구 없이 색만으로 상태를 전달하면 안 된다. |

추천은 **B**, 크게 바꾸고 싶다면 **D**다. 이는 시안의 디자인 판단이며 사용자 테스트 점수가 아니다. A의 밀도와 B의 제목·목록 위계를 조합하는 것도 가능하다. 그림자나 채도를 더하는 것보다 정보 위계·상태 피드백·일관된 간격을 먼저 맞추는 편이 완성도에 유리하다.

## 상태와 인터랙션

- 동일한 예시 데이터: 외장 화면 하나, Space 둘, Safari·Slack·Xcode·Linear 네 앱. Linear는 실행 안 됨 상태다.
- 모든 시안에 복원 준비·Space 이동 안내·복원 실패·연결 해제를 넣었다. 실패 안내는 접힌 결과 상세 밖에 남기고, 연결 해제 시 저장·복원 버튼을 비활성화한다.
- 앱 체크·자동 복원 토글은 메모리 안의 예시 상태만 바꾼다. 시안을 바꿔도 선택은 유지한다. 새로고침하면 초기화된다.
- 복원 버튼은 짧은 진행 표시 후 **고정 결과 예시**를 보여준다. 실제 창 이동이나 앱별 정책 계산은 하지 않는다. 선택한 앱 수로 결과를 재계산하는 도메인 시뮬레이터는 아니다.
- 저장·설정·종료는 시안 바깥의 상태 메시지로 범위를 알린다. 실제 설정 창·파일 기록·앱 종료에 연결하지 않는다.
- 시안의 앱 아이콘은 이 Mac에 설치된 해당 앱의 원본 아이콘에서 축소했고 외부 CDN을 요구하지 않는다. 재배포용 브랜드 자산 묶음은 아니다.

## 확인 결과

- Aside에서 4개 구성 × 2개 테마 × 4개 상태, **32개 조합**을 확인했다. 카드 가로 넘침 없음, 모든 조합에 앱 4개 표시, 연결 해제 시 복원 비활성, 안내/실패 상태의 문구 노출을 확인했다.
- 체크박스 변경 후 시안 전환에도 선택이 유지되고, 복원 진행 중 버튼이 비활성화된 뒤 고정 결과 예시가 표시되는 것을 실제 클릭으로 확인했다.
- 375px iframe의 실제 좁은 뷰포트에서 네 시안의 안내 상태를 확인했다. 발견한 그리드 최소 너비 문제를 수정했고 페이지·카드 가로 넘침이 사라졌다.
- 지정 색상 쌍을 계산한 결과, 본문/바탕 최소 **10.93:1**, 보조 글자/보조 표면 최소 **4.51:1**, 강조색/그 위 글자 최소 **5.55:1**이었다. 모든 요소의 접근성 적합성을 인증한 것은 아니다.
- 모션 감소 설정에서 전환을 없애며, 클릭 가능한 요소에 포커스 표시와 이름을 둔다. 키보드·VoiceOver 전수 검증, 다중 외장 화면, 프로필 없음·권한 없음, 시스템 글자 확대, 실제 macOS 패널의 재질·높이는 네이티브 구현 단계에서 확인해야 한다.

제품 소스와 `BRANDING.md`는 변경하지 않았다. 방향을 고른 뒤 필요한 토큰·표현만 제품으로 옮기고, 탈락 시안은 프로토타입 보존 브랜치로 정리한다.
